# 💬 ChatApp — Real-time Android Chat Application

A fully functional real-time chat application built with Java and Firebase.
Users can register, login, and exchange messages instantly across devices.

## Features
- 🔐 User Authentication (Register / Login / Logout) via Firebase Auth
- 💬 Real-time messaging using Firebase Realtime Database
- 👤 Sender name displayed on each message
- 🕐 Message timestamps
- 🎨 Chat bubbles — blue for sent, grey for received
- 📱 Clean and responsive mobile UI
- 🔒 Secure database rules (authenticated users only)

## Tech Stack
- Java (Android)
- Firebase Authentication
- Firebase Realtime Database
- RecyclerView with Custom Adapter
- Android Studio

## How to Run
1. Clone this repository
2. Open in Android Studio
3. Add your own `google-services.json` from Firebase Console
4. Run on Android device or emulator (API 24+)
